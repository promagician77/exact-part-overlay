One trip through Stable Diffusion's autoencoder

Original photoAfter the round trip

No prompt, no sampling. Just encode and decode, which every diffusion step in ComfyUI does.

Measured with TAESD, the compact Stable Diffusion autoencoder, using its official weights. The full SD autoencoder keeps more detail, but it still changes pixels. No diffusion path is pixel-exact.

So the part never goes through the model.

Two paths that meet only at the end

ControlNet regenerates the scene around the part. The part's own pixels take a separate path and are pasted back last, at an exact integer offset.

Real ComfyUI workflow

22 core nodes, opens on a stock install. The last composite node takes its pixels from the original photo, not from the sampler.
